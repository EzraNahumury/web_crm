# Revisi 7 November 2026 — Menu Merchandiser

Ringkasan untuk tim (bahasa non-teknis). Semua perubahan hari ini soal **Menu
Merchandiser baru** — pelacak (tracker) kerja merchandiser dari file Excel
`Tracker-Merchandiser-AYRES.xlsx` yang dipindah ke dalam sistem.

---

## 1. Menu Merchandiser baru (5 sub-menu)

Muncul di sidebar: **Merchandiser**. Isinya sama persis seperti sheet di file
Excel, tiap sheet jadi satu sub-menu:

| Sub-menu | Isi |
|---|---|
| **Petunjuk** | Alur kerja + catatan (menunggu balasan, revisi 3, dll). |
| **Design** | Satu baris per customer yang sudah DP Design. Isi tanggal tiap tahap (Design Awal, Revisi 1–3, Design Fix) + DP Produksi. |
| **Proofing** | Ketik No. Order → nama customer & tanggal DP Produksi **otomatis** dari sheet Design. |
| **Job Ticket** | Ketik No. Order → data header otomatis dari Design + Proofing. Lengkapi detail design, rincian size, daftar nama & nomor, serah terima. |
| **Ringkasan** | Angka KPI merchandiser, terhitung otomatis dari Design & Proofing. |

### Yang dihitung otomatis (tidak perlu diketik)
- **Status** tiap order (Antre Desain → Design Awal → Revisi 1/2/3 → Design Fix → Lanjut Proofing → … → Diserahkan ke PPIC).
- **Jumlah Revisi**, **Hari DP → Fix**.
- **Menunggu Balasan**: berapa hari kiriman terakhir belum dibalas customer.
  Oranye = 2 hari, **merah = 3 hari atau lebih** (ingatkan untuk ditelepon).
- **KPI** di Ringkasan (total DP Design, Design Fix, rata-rata revisi, dll).

### Job Ticket — bantuan otomatis
- Ukuran (size) → **Total pcs** terhitung sendiri.
- Daftar nama vs total pcs → muncul tanda **"Cocok" / "TIDAK COCOK"**.
- **Nomor punggung yang dobel** ditandai merah otomatis.

---

## 2. Export Excel

Tiap menu ada tombol **Excel**:
- **Design** → file sheet Design.
- **Proofing** → file sheet Proofing.
- **Job Ticket** → file Job Ticket (lengkap: data order, detail design, size, daftar nama-nomor, serah terima).
- **Ringkasan** → **satu file berisi semua sheet** (Design + Proofing + Ringkasan) sekaligus.

Tampilan Excel sudah dirapikan — lebar kolom pas, judul kolom kebaca penuh.

---

## 3. "Tarik dari Sistem" — isi Design otomatis (tidak manual)

Di menu **Design** ada tombol **Tarik dari Sistem** + pilihan **tanggal mulai**
(default 12 Oktober 2026). Sekali klik, baris Design terisi otomatis dari data
yang sudah ada di sistem:

| Yang terisi otomatis | Diambil dari |
|---|---|
| No. Order, Nama Customer, No. WA, Tgl DP Design | **CS Selling** — closing **Jogja / Solo / RO**, mulai tanggal pilihan s/d hari ini (data **revisi tidak** diambil) |
| Tgl DP Produksi Diterima | **bukti TF DP Produksi** yang diupload CS Order |
| Tgl Desain Awal, Revisi 1/2/3, **Nama Desainer** | **Progress Design** (akun Progress Produksi), dicocokkan lewat nama customer |

- **Nama Sales (PIC CS/Sales)** tetap diisi manual (sesuai permintaan).
- **Aman diklik berkali-kali**: sync **hanya mengisi kolom yang masih kosong**.
  Data yang sudah diketik (nama sales, tanggal feedback, Design Fix, dll) **tidak
  akan tertimpa**. Order baru ikut tertarik tiap kali diklik.

## 4. Hak akses

- **Menu Merchandiser** sudah bisa dicentang di **Setting → Role** (Hak Akses Menu).
- Role **Merchandiser** otomatis dapat menunya.
- Untuk akun lain: centang "Merchandiser" di Setting, lalu akun **login ulang**.

## Catatan penting

- Semua perubahan ini baru aktif setelah **deploy** ke server (Hostinger).
  Sekali deploy, tabel + menu otomatis dibuat.
- Pencocokan Desainer & tanggal desain memakai **nama customer** (Progress
  Design tidak menyimpan No. Order). Kalau nama di Progress Design beda jauh dari
  nama di order, bisa tidak kecocokan — tinggal dibetulkan manual di baris itu.
- Kalau nama lead di Master bukan persis "Jogja / Solo / Repeat / RO", kabari
  nama aslinya supaya filter "Tarik dari Sistem" bisa disesuaikan.
